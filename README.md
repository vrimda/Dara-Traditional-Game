# DARA — Traditional Zaar/Sayawa Strategy Game

A digital version of **DARA**, the traditional board strategy game 
of the Zaar (Sayawa) people of Northern Nigeria, Bauchi State.

## About the Game

DARA is a two-player strategy game played on a 5×6 board (30 squares).  
Each player has 12 pieces. The goal is to form three-in-a-row (mills)  
to capture your opponent's pieces.

### Features
- 🎮 Two Players (local)
- 🤖 vs Computer AI — Beginner, Moderate, Expert
- 📜 Traditional Rules (extended mills, open mouth)
- ⚡ Modified Rules (forced scoring)
- 🏆 Session scoring to ±12
- 📱 Works on mobile and desktop browsers
